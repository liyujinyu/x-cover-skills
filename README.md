# X 标题评选与人物 IP 封面 Skill

面向中文 X 平台、20–40 岁的大学生、自媒体从业者和职场人员，服务 AI 学习、工作流提效、AI 副业实践与认知成长内容。在原版 100 种封面风格上加入个人标题流程和固定人物 IP。

## 个人版工作流

1. 给出文章正文：分析主要读者、核心卖点与证据，生成 12 个不同角度的标题。
2. 从相关度、钩子、吸睛、传播、兑现、辨识六项测评，按 25/20/15/15/20/5 权重计算，推荐 3 条并解释取舍。评分是编辑评估，不代表真实点击率或保证爆款；虚构收入、效率、经历的标题淘汰。
3. **等待你明确选定标题，才开始制作封面。** 回复“继续”或“都不错”不会跳过选择；换文章后需重新确认。
4. 你选好后，自动从 100 种风格中选版式，把随包人物参考图传给绘图工具，按文章主题设计指图、操作电脑、举清单、思考等动作，保持人物身份和默认服装。
5. 生成并检查封面，默认交付 1500×600 PNG 和预览；不自动发布到 X。此尺寸是项目默认交付规格，非对平台永久规则的声明。

人物原图位于 `skills/x-cover/assets/character-reference.png`。其参考约束不保证生成完全一致，需要查看实际图像检查。原图为用户提供的 IP 素材；上游 MIT 许可不自动授予他人对该人物形象的再使用权。

### 使用

```text
用 x-cover 处理下面这篇文章：<粘贴正文>
```

收到三个标题后回复“选第 2 个”，技能会继续自动制作封面。如果你已确定标题，可说“标题就用《…》，根据下面正文做带人物 IP 的 X 封面”。

技能需要宿主 AI 和支持参考图的图像工具；不自带绘图模型、API 密钥或 X 发布功能。默认入口已内置完整风格模板，无须同时安装 100 个风格才能工作。

### 本地验证

```bash
python -m unittest discover -s tests -v
python build.py
```

个人版源文件在 `specs/personal/`，`build.py` 将其连同风格目录打包到 `skills/x-cover/`。不要直接修改生成目录，否则重建会覆盖修改。

## 原版风格库说明

分析 X 榜单长文榜 **3,917 篇长文、3,535 张封面**，把高收藏封面拆成 **11 个视觉家族、100 个风格 skill**，每个 skill 自带 PGVP 结构拆解、可填空英文提示词、中英区标题排版建议，以及从 AIGC 灵感台匹配的风格增强词。

适用于 Claude Code、Codex 等支持 `SKILL.md` 的 Agent，也可以直接当提示词库翻着用。

## 能做什么

以下是原版风格库的底层能力。个人入口 `x-cover` 始终先执行上方的标题测评和确认关卡，再自动调用这些模板；独立指定风格也不表示标题已获确认。

- 丢一篇长文标题给 Agent：“帮我做个 X 长文封面” → 路由 skill 推荐 3 个风格并直接给提示词
- 指定风格：“用 x-cover-stipple-abyss 给这篇文章出图” → 稳妥 / 强钩子 / 反差 3 个版本
- 不装 skill，直接打开 [CATALOG.md](CATALOG.md) 或 [catalog.json](catalog.json) 复制模板

## 安装

```bash
git clone https://github.com/liyujinyu/x-cover-skills.git
```

```bash
cd x-cover-skills && ./install.sh
```

默认只装自包含个人入口 `x-cover`，已经带有人物参考图、评分脚本和 100 个模板；可另装选定家族，避免 100 个 skill 描述全部挤进上下文：

```bash
./install.sh --family A,C,I
```

```bash
./install.sh --all
```

装到 Codex：`./install.sh --target ~/.codex/skills`。需要独立调用所有风格时再加 `--all`。

## 一个 skill 长什么样

```text
skills/x-cover-stipple-abyss/SKILL.md
├─ 一句话用途 / 适用分类 / 区域倾向 / 画幅
├─ 工作流（读文章 → 填变量 → 出 3 个版本 → 按模型补参数）
├─ PGVP 五段：Identity / Spatial / Visual State / Material / Lighting
├─ 英文提示词模板 + 变量填写表
├─ 中文区 / 海外区标题排版建议
├─ 灵感台风格增强词（6 条可叠加关键词）
└─ 避坑
```

## 三条结论

1. **中文区卖“你能拿到什么”，海外区卖“你会变成谁”**：前者文字占 40%~60%、直接摆交付物，后者几乎无字、靠隐喻。
2. **AI 只出底图，文字后期排**：所有模板都预留标题区。
3. **一张封面只承诺一件事**。



```bash
python3 build.py --lingan /path/to/灵感台/data.js
```
