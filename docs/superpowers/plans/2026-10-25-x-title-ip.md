# X Title and IP Cover Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task in this session.

**Goal:** Adapt x-cover for Chinese X readers aged 20–40 learning AI, improving workflows, exploring AI side income, and developing judgment.

**Architecture:** Keep the 100 original styles. Generate a self-contained personal router from maintained source files outside the regenerated skills directory. A small standard-library helper computes editorial scores; the host agent reads the article, judges evidence, waits for a human title choice, and only then uses a reference-aware image tool.

**Tech Stack:** Markdown skills, Python standard library, existing build.py and shell installer, bundled PNG reference.

**Spec:** User-approved conversation workflow, expanded below.

## Global Constraints

- Generate 12 meaningfully different titles; score six dimensions with weights 25/20/15/15/20/5; recommend three grounded titles.
- State that scores are editorial estimates, never measured CTR or guaranteed virality. Never invent income, time savings, sample size, or evidence.
- Wait for an explicit user title choice; a changed article invalidates that choice. No cover image calls before choice.
- After choice automatically select one of the 100 styles, preserve the selected title's meaning, and include the supplied character reference with a topic-specific action.
- Bundle the user's original PNG losslessly; retain identity, proportions and default clothing, allow expressions/actions/props, do not reproduce incidental corner sparkle or clothing lettering as a personal logo.
- No API keys, paid services, X publication, extra models, or unrelated repository changes.
- User explicitly authorized synchronizing the customized skill and reference image to their GitHub repository.

## Review Focus

- Unverified earnings in an otherwise attractive headline must be disqualified.
- A stale or ambiguous title choice must not unlock cover generation.
- One candidate category must not crowd out all other useful title angles without explanation.
- Rebuilding must preserve personal references/assets and keep the default router installation self-contained.
- References constrain identity but do not guarantee it; inspect actual outputs and report limits.

## Baseline

An independent agent reading only the original skill generated style suggestions without a title rubric, a confirmation gate, or a persistent character reference requirement. These are the concrete gaps addressed by this change.

## Execution rulings

- Reuse the existing clean, isolated repository clone; avoid changing the surrounding workspace checkout.
- Use the user's current attached image; earlier character preferences are out of scope.
- Keep all personal source files under specs/personal/ so the existing generated-directory cleanup cannot delete them.
- No runtime approval UI or external service is required; the conversation supplies human title selection.
- Review fixes: enforce half-point scores and avoid promoting clearly weaker titles for angle diversity; clarify README and add personal-entry guards to the 100 generated style instructions while preserving their templates.
